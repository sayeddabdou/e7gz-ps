# @e7gz/api-client

`openapi.json` generated from the backend (springdoc) + a typed TypeScript client used by the three apps. Never edit `openapi.json` by hand — run `pnpm api:gen`.

Set up by **E7-11** (CI pipeline and OpenAPI → TypeScript client); regenerated by every `Sx-P0` contract task. Owner: Sayed (author) + Abdallah (consumer).
