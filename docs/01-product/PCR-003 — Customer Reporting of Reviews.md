# E7GZ PS — PRODUCT CHANGE REQUEST PCR-003
# Customer Reporting of Reviews

**Status:** APPROVED / INCORPORATED  
**Date:** 25 September 2026  
**Applies to:** Product Specification v5.0 §49; new requirement `FR-REV-11`

## Change

A signed-in Customer may report a public Review visible to them from the Customer Mobile App. A report contains a mandatory reason and may contain optional supporting details.

Submitting a report:

- creates a durable Review Report linked to the Review and reporting User;
- does **not** automatically hide, remove or otherwise change the Review;
- does not give the Venue any moderation authority;
- makes the report available to Platform Admin alongside the existing Review moderation surface.

Platform Admin may resolve the report with a mandatory resolution note. If the Admin takes an existing moderation action (Hide, Restore, Remove or Approve where otherwise valid), the report resolution may reference that moderation event. Reporting does not introduce a new Review Status or moderation action.

## Rationale

User-generated Review content needs an in-product reporting path without weakening the existing audited moderation state machine.
